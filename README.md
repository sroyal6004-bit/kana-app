# 가나·여행 단어 연습 앱 — 배포 & 자동 업데이트 안내

한 번만 호스팅해 두면, 그다음부터는 **파일을 새로 받을 필요 없이** 앱만 열면 최신본이 자동으로 반영됩니다.
(서비스워커가 HTML을 “네트워크 우선”으로 가져오도록 만들어 두었기 때문입니다. 골프앱과 같은 방식.)

포함 파일:
- index.html
- manifest.json
- sw.js
- firebase-config.js  ← 기기 간 동기화 설정(이미 채워져 있음). 함께 올리세요.
- icon-192.png
- icon-512.png
- netlify.toml  ← Netlify 설정(무설정 배포 + 캐시 헤더). 그대로 함께 올리세요.

---

## 배포 방법 — 셋 중 하나 (한 번만)

### ★ B. GitHub + Netlify — 커밋하면 자동배포 (추천)
1. GitHub에서 새 저장소 생성 (예: `kana-app`, Public/Private 무관)
2. **Add file → Upload files** 로 아래 7개를 드래그해 올리고 커밋
   - index.html, manifest.json, sw.js, firebase-config.js, icon-192.png, icon-512.png, netlify.toml
   - (git CLI 없이 웹에서 그냥 끌어다 놓으면 됩니다)
3. Netlify → **Add new site → Import an existing project → GitHub** → 이 저장소 선택
   - `netlify.toml`이 있어서 빌드 설정은 자동으로 잡힙니다. 그대로 **Deploy** 클릭
4. 나오는 주소(`https://xxxx.netlify.app`)를 폰에서 열고 → 공유 → **홈 화면에 추가**
5. 이후 업데이트: 저장소의 파일을 **새 파일로 교체(커밋)** 하면 Netlify가 자동 배포하고, 폰/PC 앱은 다음 실행 때 자동 갱신됩니다. 다시 다운로드/설치할 필요 없음.

### A. Netlify 드래그&드롭 — 더 빠르지만 수동
1. https://app.netlify.com/drop 에 `kana-app.zip`을 끌어다 놓기
2. 나오는 주소를 폰에서 열고 홈 화면에 추가
3. 업데이트 때마다 새 zip을 같은 사이트에 다시 올려야 함(자동배포 아님)

### C. GitHub Pages
1. 저장소를 만들고 5개 파일 업로드
2. **Settings → Pages → Branch: main / (root)** 선택
3. 나오는 주소(`https://아이디.github.io/저장소명/`)를 열고 홈 화면에 추가

> 경로 문제 없음: 앱은 모든 링크를 상대경로(`./`)로 쓰고 manifest scope도 `./`라, 루트든 하위폴더든 그대로 동작합니다.

## 업데이트는 어떻게 반영되나
- 앱이 실행될 때마다 HTML을 서버에서 새로 받아오고(네트워크 우선), 서비스워커가 바뀌면 자동으로 새로고침합니다.
- 그래서 **호스팅 파일만 갱신되면** 폰/PC 앱은 알아서 최신이 됩니다.
  - A안: 새 파일을 다시 drop에 올리기(같은 사이트 선택해 덮어쓰기)
  - B안: 저장소에 커밋 → 자동배포 (가장 편함)
- 즉, 한 번 세팅 후에는 **파일 재다운로드/재설치 없이** 사용합니다.

## 진도(공부 기록)는?
- 진도는 기본적으로 브라우저(localStorage)에 저장됩니다. **같은 주소**로 접속하면 이 기기에서 계속 유지돼요.
- 앱 설정의 **진도 백업(JSON 내보내기/불러오기)** 으로 언제든 파일로 옮길 수 있습니다.

## 📱 ↔ 💻 PC·폰 기기 간 동기화 (골프앱처럼, 이제 내장됨)
- 설정(⚙️) > **기기 간 동기화**에서 PC와 폰에 **같은 연결 코드**를 넣으면 진도가 실시간으로 함께 저장됩니다.
  한쪽에서 공부하면 다른 쪽에도 **바로 반영**돼요. (별도 로그인 없이 코드만으로 연결)
- 코드는 직접 정하거나 **"새 코드 자동 생성"** 버튼으로 만들 수 있어요. 코드가 곧 비밀번호이니 남이 추측하기 어렵게 정하세요.
- **설정 불필요**: 삿포로 여행앱과 같은 Firebase를 재사용하되(`firebase-config.js`에 이미 채워져 있음),
  `kana-...` 접두어 문서에 따로 저장해 여행 데이터와 절대 섞이지 않습니다. 콘솔에서 규칙을 건드릴 필요가 없어요.
- 오프라인일 때는 이 기기에만 저장되고, 온라인이 되면 자동으로 다시 이어집니다. (동기화는 어디까지나 선택 기능)
- 병합 방식: 각 글자 기록에 수정 시각을 붙여, 두 기기가 다르면 **더 최근에 공부한 쪽**을 남깁니다.

## 현재 버전
- 서비스워커 캐시: `kana-v6`
- 가나(히라가나·가타카나 전체) + 여행 단어 142개(인사·공항·식당·이자카야·술·쇼핑·온천·골프·긴급·숫자) + 추천 술 참고 목록
- **기기 간 실시간 동기화(연결 코드 방식) 추가** — PC↔폰 진도 자동 연동
